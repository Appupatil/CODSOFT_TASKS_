# CODSOFT Data Science Internship Tasks

This repository contains the projects completed as part of my **CodSoft Data Science Internship**.

## Projects

### Task 1 – Titanic Survival Prediction
Built a machine learning model using Logistic Regression to predict whether a passenger survived the Titanic disaster.

**Techniques used:**
- Data preprocessing
- Missing value handling
- Feature selection
- Logistic Regression
- Model evaluation

### Task 2 – Movie Rating Prediction
Built a regression model to predict movie ratings using movie-related features such as genre, director, actors, year, duration, and votes.

**Techniques used:**
- Data preprocessing
- Feature engineering
- One-hot encoding
- Ridge Regression
- MAE, RMSE and R² evaluation

### Task 3 – Iris Flower Classification
Built a K-Nearest Neighbors (KNN) classification model to classify iris flowers into Setosa, Versicolor, and Virginica.

**Techniques used:**
- Data exploration
- Train-test split
- KNN classification
- Accuracy evaluation
- Confusion matrix

### Task 4 – Sales Prediction
Built a Linear Regression model to predict sales based on advertising expenditure on TV, Radio, and Newspaper.

**Techniques used:**
- Data analysis
- Correlation analysis
- Linear Regression
- MAE, RMSE and R² evaluation
- Data visualization

### Task 5 – Credit Card Fraud Detection
Built a Logistic Regression model to detect fraudulent credit card transactions.

**Techniques used:**
- Data preprocessing
- Feature normalization
- Random oversampling
- Logistic Regression
- Precision, Recall and F1-score
- Confusion matrix
